# 요양시설 스튜디오 (1단계)

주간보호센터·소형 요양원용 돌봄 업무 앱. Dolbom Studio(팀 업무 공간)를 **돌봄 현장**
쪽으로 옮긴 것.

## 무엇을 푸는가

서비스모델 논문(도우누리 주간보호센터 워크숍)의 AS-IS **문제 3 — "기록이 일과 끝에
몰린다"** 하나만 정면으로 푼다.

```
현장에서 말한다  →  초안이 채워진다  →  사람이 확인하고 저장한다  →  일지가 나온다
```

## 실행

```bash
python -m streamlit run care_studio/app.py --server.port 8533
```

## 화면 셋

| 화면 | 하는 일 |
|---|---|
| 오늘 | 시간대별 항목이 몇 명 끝났는지 + 🎤 말해서 기록 |
| 이용자 | 등록, 주의사항, **오늘 남은 것** 표시 |
| 일지 | 이용자별 하루 기록 모음 + txt 내려받기 |

## 1단계에서 하지 않는 것

상시 녹음 · 자동 확정 저장 · 의료 판단 · 공단 청구.
**저장은 항상 사람이 승인한 뒤에만** 일어난다.

## 데이터

`care_studio/data/*.json` — 이 PC 안에만 둔다. 이용자 이름·건강 상태가 들어가므로
시연·시험 단계에서 외부로 내보내지 않는다. 실제 도입 시 시설 내 서버로 옮긴다.

## 음성 (HIFA 1단계 중 '음성 기록'만)

브라우저 내장 음성인식(Web Speech API). 무료·무설정. 크롬 계열 전용.
⚠️ 음성이 구글 서버를 거친다 → 시험 단계에서는 이용자를 **가명·코드**로 부른다.
Realtime 대화·RAG·VLM은 아직 없다(HIFA 문서의 2~4단계).

## 확인한 것 / 못 한 것

- 확인함: 말 → 초안 파싱(현장 말투 6종), 기록 저장, 항목별 완료 집계, 일지 생성.
- 못 함: 실제 마이크 받아쓰기(브라우저 창에서 검증 필요), 여러 기기 동시 편집.

## 미확인 항목

- 센터가 현재 쓰는 프로그램(백정은·박재우 연구원 확인 필요).
