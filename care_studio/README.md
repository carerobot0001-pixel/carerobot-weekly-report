# 요양시설 스튜디오

주간보호센터·소형 요양원용 돌봄 업무 앱. Dolbom Studio(우리 팀 업무 공간)를
**돌봄 현장** 쪽으로 옮긴 것. 쓰는 사람만 연구원에서 요양보호사로 바뀐다.

## 실행

```bash
python -m streamlit run care_studio/app.py --server.port 8533 --server.headless true
```

폰에서 음성을 쓰려면 **HTTPS** 여야 한다(브라우저가 http 에서 마이크를 안 준다):

```bash
python -m streamlit run care_studio/app.py --server.port 8533 --server.address 0.0.0.0 \
  --server.headless true \
  --server.sslCertFile care_studio/certs/cert.pem --server.sslKeyFile care_studio/certs/key.pem
```

인증서는 자체서명이라 폰에서 경고가 뜬다 — 계속 진행하면 된다. 만드는 법:

```bash
MSYS_NO_PATHCONV=1 openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout care_studio/certs/key.pem -out care_studio/certs/cert.pem \
  -subj "/CN=care-studio-local" \
  -addext "subjectAltName=IP:<이 PC IP>,IP:127.0.0.1,DNS:localhost"
```

## 근거 — 지어낸 항목이 없다

- **급여제공기록지**: 노인장기요양보험법 시행규칙 [별지 제15호서식] (개정 2019.9.27)
  원문 PDF에서 항목을 그대로 옮겼다. 목욕 소요시간·방법, 식사 종류·섭취량,
  화장실 총 횟수, 프로그램명 기재, 구역별 작성자 서명까지 서식 유의사항 반영.
- **급여제공계획서**: [별지 제11호의4서식] (개정 2021.6.30). 작성방법(뒤쪽)의
  "급여 개시 전 작성 · 충분한 설명 후 동의 · 공단 통보"를 화면에 안내로 넣었다.
- **대장·점검 10종의 주기**: 2026년 장기요양기관 재가급여(주야간보호) 평가매뉴얼.
  프로그램 주3회, 소독 분기, 소방 매월, 재난훈련 반기, 교육·건강검진 매년 등.
  ※ 배점·세부 평가기준은 매뉴얼에 "비공개"로 명시돼 있어 담지 않았다.

## 원칙

- **자동 확정 저장 없음.** 음성이든 화면이든 사람이 누른 뒤에만 저장된다.
- **감사 기록 분리.** 서식은 최종 상태만, 누가 언제 무엇을 음성/화면 중 무엇으로
  넣었는지는 `records` 에 따로 쌓는다.
- **데이터는 이 PC 안에만.** `care_studio/data/*.json` (git 제외).
  이용자 이름·건강 상태가 들어가므로 시연 단계에서 밖으로 내보내지 않는다.

## 한계 — 분명히 해둘 것

- **PIN 로그인은 최소 잠금**이다. 시설 안 공용PC 기준. 인터넷 공개용으로는 부족하다
  (계정·2단계 인증 필요).
- **음성은 브라우저(구글) 서버를 거친다.** 시험 단계에서는 이용자를 가명·코드로 부른다.
  크롬 계열 전용. 실제 마이크 받아쓰기는 **아직 현장 검증 전**이다.
- 여러 기기 동시 편집은 범위 밖(마지막 저장 우선).
- 공단 청구 연계·보호자 알림은 없다.

## 아직 안 한 것

보호자 알림 · 청구 연계.
